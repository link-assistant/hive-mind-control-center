Server-global tool baseline
===========================

Normal auto-fix runs clean Claude/Codex global extensions before recovering
tasks, then recheck every monitor poll. Only Playwright MCP is approved as an
operator-installed default. Stock `.system` skills generated by the Codex
binary remain part of its out-of-box runtime; extra entries there are removed.
Per-task/repository capability scopes are not global defaults and are not erased.

Run only the cleanup:

```sh
node auto-fix.mjs --global-tools-only
```

Audit without changing tool state (exit 1 if dirty):

```sh
node auto-fix.mjs --global-tools-only --dry-run
```

`--diagnose` includes the read-only audit. `--no-fix-global-tools` makes the
normal check report-only. `--collect` remains collection-only. Server Python
3.11+ is required for its standard-library TOML parser.

The guard checks bot-user, bot-root and host-root tool homes when present, plus
system/managed Codex and Claude configuration layers. It removes global user
skills, plugins/marketplaces/caches, hooks/trust, custom agents/commands/global
instructions, and MCP registrations other than Playwright. It disables Codex
remote plugin synchronization and hooks, disables Claude hooks and official
marketplace auto-registration, and removes extension settings from profiles.

Removed material and original configurations are quarantined outside all tool
discovery under a root-only server directory. No installed plugin/hook code is
run during cleanup. Files backed by a single-file bind mount are edited in
place so their inode remains usable through existing mounts. Parse errors,
concurrent config edits and config aliases to credentials stop cleanup.

Auth, transcripts, projects/sessions, conversation databases, task scopes,
working trees and model/provider/permission configuration are preserved.
Credentials and config values are not printed. The local result is
`data/global-tools-last.json`; only structural findings are returned.

Regression/safety tests:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s auto-fix -p 'test_*.py' -v
node --check auto-fix.mjs
node --check auto-fix/global-tools.mjs
```

This maintenance guard is not a substitute for Hive Mind's task-launch and
deployment enforcement. Those must reject a contaminated root, isolate task
configuration, share only canonical credentials/history, and test attempted
task-to-root leaks with real Docker mounts. Auto-fix does not install a daemon
or modify already-running task capability scopes.
