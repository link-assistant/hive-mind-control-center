# Control Center migration assessment

See the [operator runbook](../../hive-manager-migration.md) for staging and cutover. This assessment uses the operational scripts at the Control Center PR base `21eb663e08fa6d1fa5751949d4534cd88818ac64`, the [upstream source-to-command audit](https://github.com/link-assistant/hive-mind/blob/v2.45.0/docs/case-studies/issue-4095/README.md), and the released manager from [Hive Mind PR #4096](https://github.com/link-assistant/hive-mind/pull/4096). The review also covers the later [legacy proxy cleanup on main](https://github.com/link-assistant/hive-mind-control-center/commit/9eab30b6f4c01868c0f068dc97628d4977159087).

## Command and caller inventory

The tracked callers and procedures are listed below. The repository has generic CI workflows. It does not contain the production SSH profile, installed crontab or systemd timer, configuration manager, bot logs, or task records. The active installations, arguments, execution accounts, and owning deployments of those callers still require confirmation at the deployment. The older files in `src/archive/` are an archived snapshot. The operator documentation points to `src/hive-control-center/`.

## Release and verification

- The pin is npm `@link-assistant/hive-mind@2.45.0`, tag commit `04886514be5dc4359820b136aca0781d5be928c8`. The installed CLI reported `2.45.0` and matched the script at that commit. The [example profile](../../../examples/hive-manager/staging.conf) pins the multiarch plain container image by digest. The registry also reports `konard/hive-mind-dind:2.45.0@sha256:04f4a42b00e258a6225d891c92893159269c31f6a4fb980c6af604db082dd2bf`. Preserve the deployed task image digest independently. [Release](https://github.com/link-assistant/hive-mind/releases/tag/v2.45.0)
- All 29 upstream manager tests passed against the installed package. They cover task recovery selection, repair and incident routing, queue reconstruction, archive privacy, retries and Git-history preservation, and Telegram text and media with a fake client. [Release tests](https://github.com/link-assistant/hive-mind/blob/v2.45.0/tests/hive-manager-4095.test.mjs)
- The upstream Docker lifecycle fixture passed for deployment replacement, interrupted update, stopped-task backup and cleanup, and proxy lifecycle. The [local staging smoke](../../../experiments/issue-1/staging-smoke.sh) added a real OpenSSH jump and target, a separate persistent state profile, and a Docker fixture. It passed diagnostics, streamed backup and restore, refusal to overwrite restored state, state-preserving update and rollback, failed startup restoration, and candidate recovery. The actual deployment's SSH route, release image startup and live daemon diagnostics are pending. [Upstream lifecycle experiment](https://github.com/link-assistant/hive-mind/blob/v2.45.0/experiments/issue-4095/docker-lifecycle.sh)
- The upstream task repair experiment with the released CLI and start-command 0.44.0 adopted a synthetic running Docker attempt, retained the previous exit 137, and verified that the watcher finalized the new attempt with exit 27. [Task record repair experiment](https://github.com/link-assistant/hive-mind/blob/v2.45.0/experiments/issue-4095/task-record-repair.sh)
- The released mount resolver translated synthetic credential, Git, and transient files in a parent container into launchable mounts on the same host Docker daemon. It refused a source stored only in the writable layer. The test used a lightweight image, separate from the watcher fixture. [Host task mount experiment](../../../experiments/issue-1/host-task-mounts.sh)
- Both Docker variants were previewed on a Docker host using the released CLI. With a host socket, the DinD plan included `--privileged`, a volume at `/var/lib/docker`, and the host socket at `/var/run/host-docker.sock`. The plain plan bound the supplied socket at `/var/run/docker.sock`. The DinD plan passed a full image reference as a tag, which the released task image resolver prefixed with a second repository. The full-reference environment variable `HIVE_MIND_DOCKER_ISOLATION_IMAGE` preserved the pinned image digest in a resolver check. An isolated task launch and watcher check in the deployed topology are still required. [Upstream report](https://github.com/link-assistant/hive-mind/issues/1962#issuecomment-7056596732)
- GitHub metadata confirmed the existing destination `konard/public-repositories-sessions-archive` was private, with `main` at `217d663dbb0e23113c8d202cf1af8f2ccb0c5651`. The repository tree had no manager `.published` index. The inspecting account had push access. The scheduler's account and source data were unavailable, and no archive content was retrieved or published. The production pause, incremental review and rollback rehearsal remain pending.
- A reviewed batch against a disposable Git remote preserved the legacy tree. The next preview skipped the published revision. Reverting the publication preserved an unrelated later commit, removed the batch and index marker, and made the revision eligible again. The fixture supplied GitHub repository visibility locally. [Archive rollback experiment](../../../experiments/issue-1/archive-rollback.sh)
- The legacy MTProxy runbook contains client-network observations including stalled media even when a text request worked. The release tests passed with a fake client. A separate fixture confirmed that a 24-byte invalid image with the PNG signature passes the released photo check. A client on the affected network and an authorized Telegram account are still required for live text and media acceptance. [Legacy network evidence](../../../src/hive-control-center/docs/MTProxy-VERIFICATION.md), [Photo fixture](../../../experiments/issue-1/proxy-photo-evidence.mjs)
- The previous Control Center security run recorded two regular-expression findings in legacy socket reporting. A regression fixture reproduced port input selecting unintended socket rows. The fallback now compares literal ports and the exact foreign TCP endpoint. The regression tests use synthetic IPv4/IPv6 and separate local and foreign endpoints. [Baseline run](https://github.com/link-assistant/hive-mind-control-center/actions/runs/44859843115)
