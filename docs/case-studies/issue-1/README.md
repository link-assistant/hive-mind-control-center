## Released features and remaining upstream work

- Release 2.48.0 includes the formerly reported archive migration, scoped disk, retry and reconcile, proxy, public library, and maintenance features. The offline `auto-fix.mjs --inspect-task-snapshot` command imports the public JavaScript library and uses upstream task counts and failure groups. The legacy backup, restart, update and auto-fix wrappers share one runtime bootstrap. Both deployment scripts remain self-contained for gist downloads and single-file SFTP staging. [Archive #4108](https://github.com/link-assistant/hive-mind/issues/4108), [Storage #4109](https://github.com/link-assistant/hive-mind/issues/4109), [Recovery #4110](https://github.com/link-assistant/hive-mind/issues/4110), [Proxy #4111](https://github.com/link-assistant/hive-mind/issues/4111), [Library #4116](https://github.com/link-assistant/hive-mind/issues/4116), [Maintenance #4117](https://github.com/link-assistant/hive-mind/issues/4117)
- Remaining upstream requests cover a profile-scoped auto-fix lifecycle and generic runbook, repeatable automatic incident reporting, private selected-source backups, oversized archive parity, and a remote package pin. The host-daemon issue also tracks the full task image reference being passed in the tag field when using DinD image passthrough. Set the full `HIVE_MIND_DOCKER_ISOLATION_IMAGE` explicitly and verify it on staging. [Auto-fix #4131](https://github.com/link-assistant/hive-mind/issues/4131), [Incident automation #4132](https://github.com/link-assistant/hive-mind/issues/4132), [Backup #4133](https://github.com/link-assistant/hive-mind/issues/4133), [Archive parity #4134](https://github.com/link-assistant/hive-mind/issues/4134), [SSH pin #4135](https://github.com/link-assistant/hive-mind/issues/4135), [Host daemon #1962](https://github.com/link-assistant/hive-mind/issues/1962#issuecomment-7056596732)

## Release and verification

- The pin is npm `@link-assistant/hive-mind@2.48.0`, tag commit `03e68e90c2642a39ebdc9e3f9231acfb7a472c3d`. The installed CLI reported 2.48.0. Registry manifests confirmed the plain digest in the [staging profile](../../../examples/hive-manager/staging.conf) and the DinD digest `sha256:53a204f8d01364b39d79c5d22a7bd645953649a79489ffe1579204442a71065f`. Preserve the deployment's task image digest independently. [Release](https://github.com/link-assistant/hive-mind/releases/tag/v2.48.0)
- The [OpenSSH staging fixture](../../../experiments/issue-1/staging-smoke.sh) used a real jump host and target with the pinned CLI and host package. It exercised host, daemon and disk diagnostics, backup and restore, refusal to overwrite restored state, state-preserving update, failed replacement, rollback, and recovery after an interrupted rollout. The published image profile was previewed by digest. The lifecycle fixture used a lightweight image.
- The [host task fixture](../../../experiments/issue-1/host-task-mounts.sh) launched an isolated task on the same host daemon with translated credential, Git and transient binds and rejected an unbacked source. The [initial upstream repair fixture](https://github.com/link-assistant/hive-mind/blob/v2.45.0/experiments/issue-4095/task-record-repair.sh) attached a watcher to a synthetic resumed task, retained exit 137 from the previous attempt and recorded exit 27 from the new attempt.
- The [archive fixture](../../../experiments/issue-1/archive-rollback.sh) imported a legacy revision into the index, filtered a synthetic private literal, published one incremental revision and verified that another preview skipped it. Reverting that publication preserved the legacy tree and import index, retained an unrelated later commit, and made the reverted revision eligible again. The local Git remote used synthetic visibility and access responses.
- GitHub metadata previously confirmed that `konard/public-repositories-sessions-archive` was private and the inspecting account had push access. The default branch `main` was at `217d663dbb0e23113c8d202cf1af8f2ccb0c5651` with no manager `.published` index. The actual scheduler account, its source data, and its current Git tip require confirmation at cutover.
- All 39 upstream manager, library and proxy tests in the selected suites passed against the installed 2.48.0 package. The [photo regression fixture](../../../experiments/issue-1/proxy-photo-evidence.mjs) rejects the signature-only photo that passed in 2.45.0. The upstream proxy tests also compare decoded pixels after simulated recompression, and check document bytes, same-port route selection, MSS/namespace evidence and scoped legacy cleanup. The client's real route still needs testing. [Manager tests](https://github.com/link-assistant/hive-mind/blob/v2.48.0/tests/hive-manager-4095.test.mjs), [Library tests](https://github.com/link-assistant/hive-mind/blob/v2.48.0/tests/hive-manager-library-4116.test.mjs), [Proxy tests](https://github.com/link-assistant/hive-mind/blob/v2.48.0/tests/hive-manager-proxy-4111.test.mjs)
- The previous Control Center security run flagged two regular expressions in legacy socket reporting. The fallback now compares literal ports and exact foreign TCP endpoints. Regression tests use synthetic IPv4 and IPv6 sockets with distinct local and foreign endpoints. [Baseline run](https://github.com/link-assistant/hive-mind-control-center/actions/runs/44859843115)
